# Travel — лендинг для туристического сервиса

Учебный проект по созданию адаптивного лендинга для туристической компании.

## 🎯 Задача проекта
Создать современный, полностью адаптивный лендинг с акцентом на:
*   Адаптивную верстку (mobile-first подход)
*   Интерактивные элементы интерфейса
*   Оптимизацию изображений и производительности
*   Чистую и поддерживаемую структуру кода

## 🛠 Технологии
*   **HTML5** — семантическая разметка
*   **CSS3** — адаптивный дизайн, анимации, переменные
*   **JavaScript** — интерактивные компоненты
*   **Git** — контроль версий
